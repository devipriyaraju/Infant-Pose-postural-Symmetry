# Reproducibility notes

The uploaded notebook used:

- seed 0
- 5 grouped folds
- source video grouping
- posture stratification
- HRNet-W32 and RTMPose-S
- three symmetry classifier seeds: 0, 1, and 2

The current reported symmetry results use geometric labels because the human survey workbook was not present in the expanded SyRIP archive available to the notebook.

When the WACV survey workbook and image mapping file are available, the same label aggregation code can switch to human label mode.
